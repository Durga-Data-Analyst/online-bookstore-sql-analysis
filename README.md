# Online Bookstore SQL Analysis Project

## 📌 Project Objective
This project analyzes transactional data from an online bookstore to generate business insights related to sales performance, customer behavior, and inventory management.

---

## 🗄 Database Design
The system consists of three core entities:

- Books
- Customers
- Orders

Relationships:
- Each order is placed by one customer
- Each order contains one book
- Books and customers are linked through the Orders table

---

## 🛠 Tools Used
- PostgreSQL
- SQL (Joins, Aggregations, CTEs, Window Functions)

---

## 📊 Business Questions Answered

- What is total revenue generated?
- Which books generate the highest revenue?
- Who are the top spending customers?
- What are monthly revenue trends?
- Which books are low in stock?

---

## 🔍 Key Insights

- Revenue is concentrated among top customers
- Certain genres outperform others in total sales
- Low-stock books require restocking strategy
